Приложение «Тренировки» (веб-приложение для iPhone)

1. Выложите ВСЕ файлы из этой папки на любой бесплатный хостинг статических сайтов
   с HTTPS (Netlify Drop, GitHub Pages или Cloudflare Pages). Файлы должны лежать в корне сайта.
2. Откройте адрес сайта в Safari на iPhone.
3. Нажмите «Поделиться» -> «На экран "Домой"».
4. Запускайте приложение с иконки.

Важно:
- Данные хранятся на телефоне для конкретного адреса сайта. Не меняйте адрес после начала занятий.
- Делайте резервную копию (вкладка «История», кнопка «Резервная копия (JSON)»).
- При изменении файлов увеличьте номер версии CACHE в sw.js.
